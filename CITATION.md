# Citation Information

Guidance on citing Alex Liu's "Stored, Not Integrated: A Pre-Treatment Predictor and Three Controls for Knowledge Injection."

**For citing the latest version**, use the concept DOI: [10.5281/zenodo.21865285](https://doi.org/10.5281/zenodo.21865285). It always resolves to the most recent release.

## Version 0.2.0 — current release

Corrects v0.1.0. The headline analysis is replaced by a single-adapter replication, one contribution is withdrawn, and several numbers change; see [`CHANGELOG.md`](CHANGELOG.md). **Cite this version, not v0.1.0.**

**Plain text**

> Alex Liu. (2026). *Stored, Not Integrated: A Pre-Treatment Predictor and Three Controls for Knowledge Injection* (v0.2.0). Zenodo. https://doi.org/10.5281/zenodo.21865285

**BibTeX**

```bibtex
@software{liu_2026_stored_not_integrated,
  author    = {Liu, Alex},
  title     = {{Stored, Not Integrated: A Pre-Treatment Predictor
                and Three Controls for Knowledge Injection}},
  month     = aug,
  year      = 2026,
  publisher = {Zenodo},
  version   = {v0.2.0},
  doi       = {10.5281/zenodo.21865285},
  url       = {https://github.com/alexliu1420/knowledge-injection-composition}
}
```

Replace the DOI above with the version DOI Zenodo mints for v0.2.0 if you need to cite that exact release; the DOI shown resolves to the latest version.
